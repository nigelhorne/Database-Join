  287: =head1 NAME
  288: 
  289: Database::Join::Catalog - List a database's tables and columns, and write a table as SQLite
  290: 
  291: =head1 VERSION
  292: 
  293: 0.011.0
  294: 
  295: =head1 SYNOPSIS
  296: 
  297:     use Database::Join::Catalog;
  298: 
  299:     my $names = Database::Join::Catalog->tables(file => 'store.db');   # [ 'customers', 'orders' ]
  300:     my $all   = Database::Join::Catalog->schema(file => 'store.db');
  301:     # [ { name => 'customers', columns => [ 'entry', 'name' ] }, ... ]
  302: 
  303:     my $info = Database::Join::Catalog->table_info(
  304:         dsn => 'dbi:MariaDB:database=shop;host=db', username => 'ro', password => '...',
  305:         table => 'orders',
  306:     );
  307:     # { columns => [ 'entry', 'item', 'qty' ], primary_key => [ 'entry' ] }
  308: 
  309:     my $bytes = Database::Join::Catalog->sqlite_bytes(
  310:         table => 'data', columns => [ 'id', 'name' ], rows => [ { id => 1, name => 'a' } ],
  311:     );
  312: 
  313:     my $driver = Database::Join::Catalog->available_driver('MariaDB', 'mysql');   # or undef
  314: 
  315: =head1 DESCRIPTION
  316: 
  317: L<Database::Abstraction> opens a table it is told the name of, and
  318: L<Database::Join> reads across such tables.  Neither says which tables a
  319: database holds, what a table's columns are in their declared order, or what
  320: its key is, and neither writes a file.  This module does those, so that an
  321: application reads and describes its data through this distribution and needs
  322: no database driver of its own.
  323: 
  324: Every method is a class method.  A database is named either by C<file>, a
  325: SQLite file, which is opened read-only (so a name that is not there is not
  326: made into an empty database), or by C<dsn> with optional C<username> and
  327: C<password>.  Listing tables works for SQLite, MariaDB and MySQL.
  328: 
  329: A database that cannot be reached, or a query it refuses, croaks with a
  330: L</Database::Join::Catalog::Error>, which says which of the two it was.
  331: Arguments that are wrong croak with a plain message.
  332: 
  333: =head1 METHODS
  334: 
  335: =head2 tables
  336: 
  337:     my $names = Database::Join::Catalog->tables(file => $path);
  338: 
  339: =head3 API SPECIFICATION
  340: 
  341: =head4 INPUT
  342: 
  343:     file:     string, a SQLite file; or
  344:     dsn:      string, a DBI data source (SQLite, MariaDB, MySQL)
  345:     username: string, optional (dsn only)
  346:     password: string, optional (dsn only)
  347: 
  348: =head4 OUTPUT
  349: 
  350: An arrayref of the table names, sorted by name.  For SQLite, the user tables
  351: (not C<sqlite_*>); for MariaDB and MySQL, those of the connection's database.
  352: A file that is not a SQLite database croaks at stage C<query>; one that is not
  353: there, at stage C<connect>.
  354: 
  355: =head2 schema
  356: 
  357:     my $tables = Database::Join::Catalog->schema(dsn => $dsn, username => $u, password => $p);
  358: 
  359: =head3 API SPECIFICATION
  360: 
  361: =head4 INPUT
  362: 
  363: As L</tables>.
  364: 
  365: =head4 OUTPUT
  366: 
  367: An arrayref of C<< { name => $table, columns => [ $column, ... ] } >>, sorted by
  368: table name, each table's columns in their declared order.  Croaks as
  369: L</tables>, and with C<error_driver_unsupported> for another driver.
  370: 
  371: =head2 table_info
  372: 
  373:     my $info = Database::Join::Catalog->table_info(dsn => $dsn, table => 'orders');
  374: 
  375: =head3 API SPECIFICATION
  376: 
  377: =head4 INPUT
  378: 
  379:     file or dsn, username, password: as tables
  380:     table:    string, required
  381: 
  382: =head4 OUTPUT
  383: 
  384: C<< { columns => [ ... ], primary_key => [ ... ] } >>: the columns in the
  385: table's declared order (L<Database::Abstraction>'s C<columns()> is
  386: alphabetical), and the primary key's columns, empty when it has none or the
  387: driver does not say.  A database that cannot be reached croaks at stage
  388: C<connect>; a table it does not have, at stage C<query>.
  389: 
  390: =head2 write_sqlite
  391: 
  392:     Database::Join::Catalog->write_sqlite(file => 'out.db', table => 'data',
  393:         columns => [ 'id', 'name' ], rows => \@rows);
  394: 
  395: =head3 API SPECIFICATION
  396: 
  397: =head4 INPUT
  398: 
  399:     file:    string, required; a name that does not exist yet
  400:     table:   string, optional (default 'data')
  401:     columns: arrayref of strings, required, at least one
  402:     rows:    arrayref of hashrefs, optional; each row's values by column name
  403: 
  404: =head4 OUTPUT
  405: 
  406: 1.  Makes a SQLite file with one table whose columns are TEXT, in the order
  407: given, and one row for each element of C<rows> (a missing value is NULL).
  408: Names are quoted, so any column name is safe.  The rows go in one transaction.
  409: Croaks with C<error_file_exists> rather than replace a file, and leaves no
  410: file behind when the write fails.
  411: 
  412: =head2 sqlite_bytes
  413: 
  414:     my $bytes = Database::Join::Catalog->sqlite_bytes(columns => \@columns, rows => \@rows);
  415: 
  416: =head3 API SPECIFICATION
  417: 
  418: =head4 INPUT
  419: 
  420: As L</write_sqlite>, without C<file>.
  421: 
  422: =head4 OUTPUT
  423: 
  424: The SQLite file's contents, made in a temporary file that is removed
  425: afterwards, whether or not the write succeeds.
  426: 
  427: =head2 available_driver
  428: 
  429:     my $driver = Database::Join::Catalog->available_driver('MariaDB', 'mysql');
  430: 
  431: =head3 API SPECIFICATION
  432: 
  433: =head4 INPUT
  434: 
  435:     @names: DBD driver names, in order of preference
  436: 
  437: =head4 OUTPUT
  438: 
  439: The first whose C<DBD::> module loads, or undef.  A name that is not a
  440: driver name is skipped, never loaded.
  441: 
  442: =head1 Database::Join::Catalog::Error
  443: 
  444: What a failed C<connect> or C<query> croaks with.  It reads as the driver's
  445: message (C<"$err">), and:
  446: 
  447:     $err->stage     # 'connect' or 'query'
  448:     $err->message   # the driver's message
  449: 
  450: =head1 MESSAGES
  451: 
  452:     error_source_required    -- neither file nor dsn (or write_sqlite without file)
  453:     error_source_both        -- both file and dsn
  454:     error_driver_unsupported -- schema() or tables() for a driver other than SQLite, MariaDB, MySQL
  455:     error_table_required     -- table_info() without a table, or an empty table name
  456:     error_columns_required   -- write_sqlite() or sqlite_bytes() without columns
  457:     error_row_not_hash       -- an element of rows is not a hashref
  458:     error_file_exists        -- write_sqlite() to a name that exists
  459:     error_temp_file          -- sqlite_bytes() could not make its temporary file
