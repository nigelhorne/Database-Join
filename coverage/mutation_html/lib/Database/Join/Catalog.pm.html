  289: =head1 NAME
  290: 
  291: Database::Join::Catalog - List a database's tables and columns, and write a table as SQLite
  292: 
  293: =head1 VERSION
  294: 
  295: 0.011.1
  296: 
  297: =head1 SYNOPSIS
  298: 
  299:     use Database::Join::Catalog;
  300: 
  301:     my $names = Database::Join::Catalog->tables(file => 'store.db');   # [ 'customers', 'orders' ]
  302:     my $all   = Database::Join::Catalog->schema(file => 'store.db');
  303:     # [ { name => 'customers', columns => [ 'entry', 'name' ] }, ... ]
  304: 
  305:     my $info = Database::Join::Catalog->table_info(
  306:         dsn => 'dbi:MariaDB:database=shop;host=db', username => 'ro', password => '...',
  307:         table => 'orders',
  308:     );
  309:     # { columns => [ 'entry', 'item', 'qty' ], primary_key => [ 'entry' ] }
  310: 
  311:     my $bytes = Database::Join::Catalog->sqlite_bytes(
  312:         table => 'data', columns => [ 'id', 'name' ], rows => [ { id => 1, name => 'a' } ],
  313:     );
  314: 
  315:     my $driver = Database::Join::Catalog->available_driver('MariaDB', 'mysql');   # or undef
  316: 
  317: =head1 DESCRIPTION
  318: 
  319: L<Database::Abstraction> opens a table it is told the name of, and
  320: L<Database::Join> reads across such tables.  Neither says which tables a
  321: database holds, what a table's columns are in their declared order, or what
  322: its key is, and neither writes a file.  This module does those, so that an
  323: application reads and describes its data through this distribution and needs
  324: no database driver of its own.
  325: 
  326: Every method is a class method.  A database is named either by C<file>, a
  327: SQLite file, which is opened read-only (so a name that is not there is not
  328: made into an empty database), or by C<dsn> with optional C<username> and
  329: C<password>.  Listing tables works for SQLite, MariaDB and MySQL.
  330: 
  331: A database that cannot be reached, or a query it refuses, croaks with a
  332: L</Database::Join::Catalog::Error>, which says which of the two it was.
  333: Arguments that are wrong croak with a plain message.
  334: 
  335: =head1 METHODS
  336: 
  337: =head2 tables
  338: 
  339:     my $names = Database::Join::Catalog->tables(file => $path);
  340: 
  341: =head3 API SPECIFICATION
  342: 
  343: =head4 INPUT
  344: 
  345:     file:     string, a SQLite file; or
  346:     dsn:      string, a DBI data source (SQLite, MariaDB, MySQL)
  347:     username: string, optional (dsn only)
  348:     password: string, optional (dsn only)
  349: 
  350: =head4 OUTPUT
  351: 
  352: An arrayref of the table names, sorted by name.  For SQLite, the user tables
  353: (not C<sqlite_*>); for MariaDB and MySQL, those of the connection's database.
  354: A file that is not a SQLite database croaks at stage C<query>; one that is not
  355: there, at stage C<connect>.
  356: 
  357: =head2 schema
  358: 
  359:     my $tables = Database::Join::Catalog->schema(dsn => $dsn, username => $u, password => $p);
  360: 
  361: =head3 API SPECIFICATION
  362: 
  363: =head4 INPUT
  364: 
  365: As L</tables>.
  366: 
  367: =head4 OUTPUT
  368: 
  369: An arrayref of C<< { name => $table, columns => [ $column, ... ] } >>, sorted by
  370: table name, each table's columns in their declared order.  Croaks as
  371: L</tables>, and with C<error_driver_unsupported> for another driver.
  372: 
  373: =head2 table_info
  374: 
  375:     my $info = Database::Join::Catalog->table_info(dsn => $dsn, table => 'orders');
  376: 
  377: =head3 API SPECIFICATION
  378: 
  379: =head4 INPUT
  380: 
  381:     file or dsn, username, password: as tables
  382:     table:    string, required
  383: 
  384: =head4 OUTPUT
  385: 
  386: C<< { columns => [ ... ], primary_key => [ ... ] } >>: the columns in the
  387: table's declared order (L<Database::Abstraction>'s C<columns()> is
  388: alphabetical), and the primary key's columns, empty when it has none or the
  389: driver does not say.  A database that cannot be reached croaks at stage
  390: C<connect>; a table it does not have, at stage C<query>.
  391: 
  392: =head2 write_sqlite
  393: 
  394:     Database::Join::Catalog->write_sqlite(file => 'out.db', table => 'data',
  395:         columns => [ 'id', 'name' ], rows => \@rows);
  396: 
  397: =head3 API SPECIFICATION
  398: 
  399: =head4 INPUT
  400: 
  401:     file:    string, required; a name that does not exist yet
  402:     table:   string, optional (default 'data')
  403:     columns: arrayref of strings, required, at least one
  404:     rows:    arrayref of hashrefs, optional; each row's values by column name
  405: 
  406: =head4 OUTPUT
  407: 
  408: 1.  Makes a SQLite file with one table whose columns are TEXT, in the order
  409: given, and one row for each element of C<rows> (a missing value is NULL).
  410: Names are quoted, so any column name is safe.  The rows go in one transaction.
  411: Croaks with C<error_file_exists> rather than replace a file, and leaves no
  412: file behind when the write fails.
  413: 
  414: =head2 sqlite_bytes
  415: 
  416:     my $bytes = Database::Join::Catalog->sqlite_bytes(columns => \@columns, rows => \@rows);
  417: 
  418: =head3 API SPECIFICATION
  419: 
  420: =head4 INPUT
  421: 
  422: As L</write_sqlite>, without C<file>.
  423: 
  424: =head4 OUTPUT
  425: 
  426: The SQLite file's contents, made in a temporary file that is removed
  427: afterwards, whether or not the write succeeds.
  428: 
  429: =head2 available_driver
  430: 
  431:     my $driver = Database::Join::Catalog->available_driver('MariaDB', 'mysql');
  432: 
  433: =head3 API SPECIFICATION
  434: 
  435: =head4 INPUT
  436: 
  437:     @names: DBD driver names, in order of preference
  438: 
  439: =head4 OUTPUT
  440: 
  441: The first whose C<DBD::> module loads, or undef.  A name that is not a
  442: driver name is skipped, never loaded.
  443: 
  444: =head1 Database::Join::Catalog::Error
  445: 
  446: What a failed C<connect> or C<query> croaks with.  It reads as the driver's
  447: message (C<"$err">), and:
  448: 
  449:     $err->stage     # 'connect' or 'query'
  450:     $err->message   # the driver's message
  451: 
  452: =head1 MESSAGES
  453: 
  454:     error_source_required    -- neither file nor dsn (or write_sqlite without file)
  455:     error_source_both        -- both file and dsn
  456:     error_driver_unsupported -- schema() or tables() for a driver other than SQLite, MariaDB, MySQL
  457:     error_table_required     -- table_info() without a table, or an empty table name
  458:     error_columns_required   -- write_sqlite() or sqlite_bytes() without columns
  459:     error_row_not_hash       -- an element of rows is not a hashref
  460:     error_file_exists        -- write_sqlite() to a name that exists
  461:     error_temp_file          -- sqlite_bytes() could not make its temporary file
  462:     error_no_reason          -- the driver failed without a message (connect returned undef)
